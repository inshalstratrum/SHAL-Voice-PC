# Use Cases

SHAL Voice PC is being developed for natural-language operation of a Windows desktop from an Android phone.

## Hands-free Windows control

Examples:

- open an application
- switch windows
- change volume
- navigate File Explorer
- read what is visible on screen
- interact with settings

## Multimodal desktop automation

A task can combine:

- visible screen understanding
- structured accessibility controls
- keyboard shortcuts
- pointer interaction
- native Windows actions

## Accessibility experiments

The project may be useful for experimenting with alternative computer-control interfaces where voice, visual understanding, and structured accessibility APIs work together.

## Remote computer assistance

The Android controller can act as a lightweight remote command and observation interface while private networking provides connectivity.

## AI computer-use research

The architecture is relevant to research and prototyping around:

- multimodal agents
- GUI grounding
- action verification
- computer vision for desktop interfaces
- safe autonomous control
- recovery after unexpected UI changes

## Long-running desktop tasks

Future workflows include monitoring applications, waiting for visible completion states, and reporting results without continuous manual supervision.
