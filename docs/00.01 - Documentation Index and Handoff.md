## Universal Control Loop
```mermaid
flowchart LR
    A[Voice Goal] --> B[Observe]
    B --> C[Understand State]
    C --> D[Plan One Safe Action]
    D --> E{Confirmation Needed?}
    E -- Yes --> F[Phone Approval]
    E -- No --> G[Execute]
    F --> G
    G --> H[Verify]
    H --> I{Goal Complete?}
    I -- No --> B
    I -- Yes --> J[Speak Result]
```

> [!important] Control philosophy
> Do not expand this system by adding hundreds of one-off voice phrases. Build a stateful observe → understand → act → verify → recover loop.
