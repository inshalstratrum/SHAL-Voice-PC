## Universal Observe-Plan-Act-Verify Loop
```mermaid
stateDiagram-v2

    Plan --> RiskCheck

    RiskCheck --> Execute: safe
    Confirm --> Execute: approved
    Confirm --> Cancelled: rejected
    Execute --> Verify
    Verify --> Complete: goal achieved
    Verify --> Recover: expected state missing
    Recover --> Observe
    Complete --> [*]
    Cancelled --> [*]
```
