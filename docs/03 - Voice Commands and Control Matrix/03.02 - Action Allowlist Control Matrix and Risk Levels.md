## State-Aware Toggles
For "turn X on/off" or "enable/disable X":
1. read current state
2. compare target state
3. do nothing if already correct
4. toggle only when required
5. verify final state

## Control Priority
```mermaid
flowchart TD
    A[Goal] --> B{Native action?}
    B -- Yes --> N[Native API]
    B -- No --> C{App adapter?}
    C -- Yes --> AP[Adapter]
    C -- No --> D{Accessible control?}
    D -- Yes --> UI[UI Automation]
    D -- No --> E{Keyboard shortcut?}
    E -- Yes --> K[Keyboard]
    E -- No --> F{Vision target?}
    F -- Yes --> V[Vision pointer]
    F -- No --> M[Coordinate fallback]
    N --> Z[Verify]
    AP --> Z
    UI --> Z
    K --> Z
    V --> Z
    M --> Z
```

> [!danger]
> The planner must not invent arbitrary PowerShell, CMD or executable paths.
