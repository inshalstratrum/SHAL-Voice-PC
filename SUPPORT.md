# Support

## Before opening an issue

Please check the README and existing issues first.

For bug reports, include:

- Windows version
- Android device and Android version
- whether the issue involves UI Automation, vision control, keyboard/mouse, native Windows control, networking, or the mobile app
- exact steps to reproduce
- expected behavior
- actual behavior

Sanitize logs and screenshots before posting. Never include pairing keys, API tokens, remote-access passwords, or other credentials.
